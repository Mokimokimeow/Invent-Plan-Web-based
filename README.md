# R&K's Mini Donut — Web-Based Inventory Management System

A web-based inventory management system developed as my **Senior High School Capstone Project** and the **first major project completed and approved by our team**.

This project was created to demonstrate how a web-based system can be connected to a database and used for managing inventory-related information.

## 📌 Project Status

**Status:** Completed ✅

The system is fully developed and functional. Some console errors may still appear when inspecting the application through the browser's Developer Tools. These can be useful for debugging, learning, and further development.

## ✨ Features

* Web-based inventory management
* Database integration
* Create and manage database records
* User interface for managing inventory data
* Frontend-to-database connection
* Local development environment using XAMPP

## 🛠️ Requirements

Before running the project, install:

* **XAMPP**
* A modern web browser
* The project source code

XAMPP provides the local Apache web server and MySQL database environment required by the system.

## 🚀 Installation & Setup

### 1. Install XAMPP

Download and install XAMPP on your computer.

After installation, open the **XAMPP Control Panel**.

### 2. Start the Required Services

Start:

* **Apache**
* **MySQL**

Make sure both services are running before opening the project.

### 3. Access the Local Server

Open your browser and visit:

```text
http://localhost:80
```

Depending on your XAMPP configuration, you may also be able to access the project through:

```text
http://localhost/
```

### 4. Configure the Database

Open:

```text
http://localhost/phpmyadmin
```

From phpMyAdmin, you can:

* Create a new database
* Create and modify tables
* Import database files
* Insert and manage records
* Connect the database to the application
